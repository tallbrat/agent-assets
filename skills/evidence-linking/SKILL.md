# Evidence Linking

## Use when
- A changed note references a concept already explained elsewhere.
- A note makes a claim that would benefit from a supporting note link.

## Do
- Add a small number of high-value links.
- Prefer links that reduce future search effort.
- Keep anchor text natural.

## Avoid
- Dense link spam.
- Creating links based on weak association only.
