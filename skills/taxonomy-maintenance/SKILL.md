# Taxonomy Maintenance

## Use when
- A changed note uses inconsistent headings, categories, or tags.
- A note should be aligned with an existing vault convention.

## Do
- Prefer the smallest alignment that matches existing local patterns.
- Use explicit headings and stable names.
- Improve discoverability without flattening nuance.

## Avoid
- Retagging large portions of the vault.
- Inventing new taxonomies when the vault already has a working one.
