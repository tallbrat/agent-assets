# Note Curation

## Use when
- A changed note is structurally weak, unclear, or missing links.
- The note benefits from a short summary or clearer headings.
- The note should stay mostly intact but become easier to use later.

## Do
- Keep edits local to the changed note unless one nearby linked note clearly needs a matching update.
- Add structure only when it improves retrieval.
- Preserve factual meaning and user intent.

## Avoid
- Rewriting the entire note for style alone.
- Renaming files unless there is a strong organizational reason.
- Deleting original content that may still be useful context.
