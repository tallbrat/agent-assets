# Incremental Editing Policy

## Principle
The curator should make the smallest set of edits that produces a meaningful improvement.

## Do
- Prefer local edits in changed notes.
- Update a neighboring note only when the relationship is direct and useful.
- Preserve stable file paths unless organization clearly improves.
- Leave large restructures for explicit future passes.

## Avoid
- Rewriting a note for tone alone.
- Reorganizing folders because a different taxonomy might be nicer.
- Applying new prompt preferences to old notes at scale.
